## 🛰️ About This Repository

Welcome to my **IoT Projects Repository** - a collection of embedded systems, wireless communication, and cybersecurity-focused projects built using modern IoT technologies.

This repository explores the intersection of **hardware, networking, and security**, focusing on creating smart and secure connected devices.
